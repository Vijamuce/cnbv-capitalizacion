CNBV · Solvencia financiera

Capitalización de las instituciones financieras en México

El ICAP mide el capital de una institución frente a sus activos ponderados por riesgo: entre más alto, mayor su colchón para absorber pérdidas inesperadas.

Esta página se actualiza automáticamente cada semana vía GitHub Actions, que revisa si la CNBV publicó boletines nuevos para cada sector. La mayoría de las semanas no hay cambios: la CNBV publica cifras mensuales, con varias semanas de rezago. Código y datos fuente en GitHub.
